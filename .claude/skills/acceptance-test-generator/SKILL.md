# 驗收清單產出

讀規格頁 → 規劃一條主流程 → 輸出帶勾選欄的 Excel 給驗收人使用。

## 驗收的範圍

驗收的目的是確認「功能照規格做出來、主流程走得通」，不是取代 QA。範圍太大會讓驗收拖過一小時、驗收人失去耐心，所以：

- **只驗主流程**：選一條最常見的路徑走完，不逐一測每個選項。
- **邊界條件、例外狀況、全選項覆蓋留給 QA。**
- **同類選項只挑一個代表**（例如多種分類、多種方案，挑最常用的一個驗）。
- **目標一小時內驗完**。預估超過時，在注意事項 sheet 提醒提前和 PM 溝通。

需要開發配合的情境要特別標出來，因為這些沒事先準備，驗收當天就卡住：
- 要跨日或排程才會觸發的功能（每日報表彙整、排程寄信、定時上架）→ 單獨一列、標 ⚠️，說明需請開發提前觸發。
- 要先建好測試資料的 → 放進「驗收前準備」，類型標「前置」，底色淡黃。

## 步驟

### 1. 讀規格頁

用當下環境可用的瀏覽器工具開啟網址：
1. 先抓整頁文字。
2. 從頁首開始截圖，往下捲動逐段截圖到頁尾。UI mockup、後台設定截圖、流程圖、欄位說明常常只出現在圖片裡，只讀文字會漏掉。
3. 文字和圖片合起來理解規格。

頁面需要登入或打不開時，請使用者提供權限或改貼內容，不要憑標題猜規格。

### 2. 整理規格重點

- 功能目標：做什麼、為什麼做
- **後台**：設定路徑、新增或修改的欄位、邏輯規則
- **前台／使用者端**：影響哪些畫面、顯示邏輯
- **紀錄與報表**：後台查詢頁、紀錄頁會不會跟著變
- **是否需要跨日或排程觸發** → 決定要不要加開發配合的 STEP

規格沒寫清楚的地方，列在回覆裡請使用者確認，不要自己補規則。

### 3. 規劃主流程

依實際操作順序排 STEP，常見骨架：

```
後台建立設定／內容
  → 前台操作，產生資料
  → （需要時：請開發提前手動觸發排程）
  → 前台確認結果顯示
  → 後台查詢紀錄核對
```

每個 STEP 只列主流程必要的項目。

### 4. 產出 Excel

用 openpyxl 建立兩個 sheet。

**Sheet 1：驗收清單**

| 欄 | 名稱 | 內容 |
|----|------|------|
| A | # | 前置用 P1/P2，正式項目用 1/2/3… |
| B | 階段 | 前置／後台／前台 |
| C | 驗收項目說明 | 要驗什麼（簡短） |
| D | 驗收動作／預期結果 | 驗收人做什麼、看到什麼才算過 |
| E | ✅ 完成 | 勾選欄，驗收人手動填 ✓ |
| F | 備註 | 驗收人記錄用 |

樣式：
- 主標題列：深藍底白字 `1F3864`
- STEP 標題列：中藍底白字 `2F5496`
- 前置項目：淡黃底 `FFF2CC`
- 一般項目：白／淡藍交錯 `FFFFFF` / `EBF3FB`
- ✅ 完成欄：淡綠底 `E2EFDA`；備註欄：淡灰底 `F2F2F2`
- ⚠️ 開發配合列：淡橘底 `FCE4D6`、紅字
- 字型 Arial 10pt；列高：項目 40、STEP 22
- 凍結到第 3 列（欄標題）；欄寬 A=6、B=14、C=45、D=30、E=12、F=12

**Sheet 2：驗收注意事項**（固定內容）

```
1. 驗收時間原則上以最長 1 小時為限；若預期需更長時間，請提前與 PM 溝通，以利安排時程。
2. 如驗收功能需開發配合（如提前觸發排程、批次處理），請事先與開發確認並完成準備。
3. 若需求需預先建立測試資料，請提前準備，以確保驗收時可直接進行驗證。
```

有跨日或排程需求時，加一段「本次驗收特別提醒」（淡黃底），寫明要和開發確認觸發時間。

### 輔助函式

```python
from openpyxl import Workbook
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side

def fill(hex_color):
    return PatternFill("solid", start_color=hex_color, fgColor=hex_color)

def border():
    s = Side(style="thin", color="BFBFBF")
    return Border(left=s, right=s, top=s, bottom=s)

def cell_style(ws, row, col, value="", bold=False, fg="000000", bg=None,
               align="left", wrap=False, size=10):
    c = ws.cell(row=row, column=col, value=value)
    c.font = Font(name="Arial", bold=bold, color=fg, size=size)
    c.alignment = Alignment(horizontal=align, vertical="center", wrap_text=wrap)
    c.border = border()
    if bg:
        c.fill = fill(bg)
    return c
```

### 5. 交付前檢查

- 用 openpyxl 重新開檔，確認兩個 sheet 都在、項目數和規劃一致、凍結窗格正確。
- 每一列的「預期結果」都要是看得到、可以判斷對錯的描述（「顯示正確」不夠，要寫「列表第一筆顯示剛建立的標題」）。

## 輸出

- 檔名：`驗收清單_[功能名稱].xlsx`，用當下環境的檔案交付方式提供。
- 回覆簡短說明：幾個 STEP、幾個驗收項目、需不需要開發配合、規格有哪些地方待確認。
