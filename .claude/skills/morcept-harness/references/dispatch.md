# dispatch.md — 模型調度守則

**適用：能派 subagent 的環境**（Claude Code；Cowork 在環境允許、使用者同意時）。claude.ai 對話介面沒有 subagent 也不能切換模型，本檔不適用，請依 SKILL.md 的環境表處理。

> 適用對象：主對話中的任何模型。規則寫成可以直接執行的判準。
> 型號會隨改版變動，本檔只用 haiku / sonnet / opus 三個等級別名，不寫死版本號；實際可用清單用 `/model` 查。

## 1. 指揮官不下場
主對話 = 指揮官。以下工作**一律派 subagent**，主對話只收結論：
- 讀取預估 >300 行，或 >2 個檔案
- 掃 repo / 找出所有呼叫點 / 盤點結構 → 用內建 **Explore** agent（Haiku，快且便宜）
- 任何網頁搜尋與研究
- 批次改檔（同一模式套用到多處）
- 驗收審查（見第 6 節，必須 fresh context）

例外：只看 1 個小檔（<300 行）的單點確認，主對話直接讀，不必派工。

## 2. 派工三件套（缺一件就不准送出）
每個派工 prompt 必含：
1. **目標與動機**：做什麼 + 為什麼（動機讓 subagent 遇到邊界情況能自行做對的取捨）
2. **驗收條件**：可勾選的清單，每條可客觀判定真假
3. **回報格式**：明確指定（見第 5 節回報合約）

模板直接用 references/templates.md（專案內則是 ops/templates.md），不要即興寫。

## 3. 模型選擇表
| 任務類型 | 模型 | effort |
|---|---|---|
| 機械批次：grep/盤點/格式轉換/套用已知模式 | haiku | 預設（不支援 effort 的版本就不設）|
| 一般實作、重構、研究、文件 | sonnet | high（預設即可） |
| 架構決策、纏繞型 debug、驗收評審、高風險判斷 | opus | high；卡關升 xhigh 或 max |
| 主對話（指揮官） | 你的預設模型 | high |

- 在 subagent frontmatter 指定 `model: haiku|sonnet|opus`（別名會自動指向當前版本，優先用別名，不要寫死完整型號 ID）。`effort:` 也可以寫進 frontmatter。
- 臨時調整：`/effort`（滑桿或直接 `/effort xhigh`）；單回合加深推理可在 prompt 內寫 `ultrathink`。
- 實際可用型號和預設 effort 依方案而定，有疑問就用 `/model` 查，不要憑記憶假設。

## 4. 升降級路徑
- **Haiku 錯 1 次** → 不重試，直接升 Sonnet。
- **Sonnet 同一子任務連錯 2 次** → 帶完整失敗軌跡（做了什麼、期望 vs 實際、錯誤訊息原文）升 Opus。禁止只丟原題重來。
- **Opus 解出來之後** → 把解法寫成明確步驟，降回 Haiku/Sonnet 批次套用到其餘位置。
- **同一件事最多重試 2 輪**。第 3 輪前必須改變做法：換模型、換路徑、或按 judgment.md 第 3 節去問使用者。重試時 prompt 必須包含前次失敗軌跡。

## 5. 回報合約（subagent 必須遵守，違反 = 重派）
- 只回：**結論 + 證據位置（檔案:行號）+ 驗收清單勾選結果**
- 長產物（報告、程式碼、掃描結果）落檔，回傳路徑，**不貼原文**
- 找不到 / 做不到就直說，並回報已排除了什麼。禁止用猜測填空
- 主對話收到不合約的回報：不要自己動手補救，重派一次並引用本節

## 6. 驗證不自驗
寫的人不能當驗的人。驗收一律派 **fresh-context** subagent（新開、不繼承對話）：
- **檔案**：read-back —— 驗證者從磁碟重讀檔案，逐條核對驗收清單，不看寫入者的自述
- **程式碼**：跑測試或實跑（HTML 至少過 verify_html.py + 在瀏覽器/headless 開啟不噴錯）
- **高風險判斷**（動客戶資料、動權限規則、動金額計算）：加第二意見 —— 派兩個獨立 subagent 各給答案，主對話比對；不一致就升 Opus 評審選優
- 驗收者只回「逐條 PASS/FAIL + FAIL 的證據」，不給修法（修是原執行者的事）

## 7. Token 紀律
- 主對話發現自己在逐行讀大檔 → 停，改派 Explore
- 同一份內容不進入主對話兩次（第一次就該落檔或摘要）
- 派工失敗的 subagent 輸出不要整段貼回主對話，只提取失敗軌跡三要素（做了什麼/期望/實際）
