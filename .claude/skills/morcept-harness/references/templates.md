# templates.md — 派工 Prompt 模板

> 用法：整段複製，填掉【】，不要刪任何區塊。模型/effort 選擇查 dispatch.md 第 3 節。
> 每份模板結尾的「回報合約」是 dispatch.md 第 5 節的落地版，照抄即可。

---
## T1 搜尋 / 盤點（建議 model: haiku，或直接用內建 Explore agent）
```
目標：在【範圍：目錄或檔案清單】中找出【找什麼，例：所有呼叫 calcBonus 的位置】。
動機：【為什麼找，例：要改參數順序，需要知道全部影響點】。
驗收條件：
- [ ] 逐一列出每個命中：檔案路徑:行號 + 該行原文
- [ ] 明確聲明搜尋過的範圍（哪些目錄、用什麼 pattern）
- [ ] 若命中為 0，回報「已搜 X，pattern 為 Y，命中 0」而非空白
回報格式：僅回清單與範圍聲明。不要解釋每個命中的意義，不要建議修法。
```

## T2 實作（建議 model: sonnet, effort: high）
```
目標：【做什麼，一句話】。
動機：【使用者要解決什麼問題；遇到規格沒寫到的邊角，往這個動機的方向取捨】。
背景：先讀【STATE.md 路徑】和【相關檔案，≤3 個】。既定慣例以 STATE.md 為準。
限制：
- 改既有檔前先備份（cp file file.bak-日期）
- 大型 HTML 禁止整檔重寫，錨點替換，改完跑 tools/verify_html.py
- 不動【明確排除的範圍】
驗收條件（每條可客觀判定）：
- [ ]【功能行為 1，例：PM 端 toggle 關閉時，客戶頁不出現 SEO 區塊】
- [ ]【功能行為 2】
- [ ] verify_html.py / 測試通過，貼輸出
- [ ] 備份檔存在
回報格式：改動摘要（每個檔案:改了什麼，各一行）+ 驗收清單勾選 + 驗證輸出。程式碼不貼回，只給路徑。
```

## T3 重構（建議 model: sonnet, effort: high；動架構升 opus）
```
目標：把【對象】從【現狀】改為【目標形態】，外部行為不變。
動機：【例：重複邏輯已在三處各自演化，下次改功能會漏】。
不變式（重構前先建立，重構後必須全數維持）：
- [ ]【可觀察行為 1，例：五種方案模板產出的 HTML 與重構前逐位元相同 / diff 僅限空白】
- [ ]【行為 2】
步驟要求：先寫下不變式的驗證方法並跑一次記錄基準，再動手，改完重跑比對。
驗收條件：
- [ ] 全部不變式驗證通過，附前後比對輸出
- [ ] 沒有夾帶行為變更（diff 中每一處都能對應到重構目的）
回報格式：不變式驗證結果 + diff 摘要（檔案:行號）。基準與比對輸出落檔附路徑。
```

## T4 研究（建議 model: sonnet, effort: high；用得到網路工具的 agent）
```
目標：回答【具體問題，例：LINE Messaging API 的 webhook 重送機制與去重做法】。
動機：【這個答案要拿去做什麼決定】。
要求：
- 優先官方文件與原始來源；每個關鍵結論附來源 URL 與查閱日期
- 區分「文件明說的」與「你推斷的」，推斷要標注
- 查不到就寫「未找到，已查過：【來源清單】」，禁止腦補
驗收條件：
- [ ] 直接回答了問題（先給結論，再給依據）
- [ ] 每個結論有來源或標注為推斷
- [ ] 有一節「對我們的影響」對應到動機
回報格式：結論（≤5 行）→ 依據與來源 → 對我們的影響。全文落檔，主對話只回結論與路徑。
```

## T5 審查 / 驗收（建議 model: opus, effort: high；必須 fresh context，不看執行者對話）
```
角色：你是驗收者，與執行者無關。只依磁碟上的實際內容判定，不採信任何自述。
目標：驗收【產物路徑】是否滿足下列條件。
驗收清單（逐條判 PASS/FAIL）：
- [ ]【條件 1】
- [ ]【條件 2】
- [ ] （HTML 必加）verify_html.py 通過、開啟後 console 無錯誤
判定規則：
- 每條 FAIL 必須附證據（檔案:行號、實跑輸出、比對差異）
- 不確定 = FAIL（寧可誤殺）
- 只判定，不修復，不給修法建議
回報格式：逐條 PASS/FAIL 清單 + FAIL 證據。無其他內容。
```

---
## 填模板時最常見的三個錯（自檢）
1. 驗收條件寫成期望而非可判定命題。「功能正常運作」✗ →「toggle 關閉時 DOM 中不存在 #seo-section」✓
2. 忘了給動機。沒有動機的 subagent 遇到邊角只能亂猜。
3. 背景檔給太多。>3 個檔案表示你還沒想清楚範圍，先派 T1 盤點。
